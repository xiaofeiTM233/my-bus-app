# my-bus-app | 掌上公交

基于 Flutter 打造的跨平台公交实时查询客户端，复刻原版掌上公交 App 的公开查询体验：查线路、看站牌、盯车辆、找附近站点、地图查车。数据直连公交厂商公开查询接口（h5.mygolbs.com），无需登录、无需注册任何地图 key。

支持 **Android / iOS / Windows / macOS / Linux / Web** 六端运行。

## ✨ 核心特性

- 🏙️ **全量城市覆盖**：启动拉取全部 565 个服务城市，搜索过滤 + 手动输入即可切换，记忆上次城市
- 📍 **定位选城**：城市选择页一键「定位选择当前城市」——GPS 定位 → 逆地理编码识别城市名 → 自动匹配服务城市；识别失败时按历史城市中心就近兜底，不在服务列表则允许强行使用
- 🔍 **线路 / 站点双搜索**：双模式搜索（CMD114 / CMD110），线路空结果自动补「路」重试，兼容各城市命名差异
- 🚌 **线路详情实时盯车**：进入即轮询全线车辆（无需先选站）；上下行切换、首末班时间、站点时间轴按车辆实际位置分布，行驶中（橙）/ 已到站（蓝徽章）状态分明，标注「只上不下」等停靠属性；点选站点获得精确到站预测（车牌、剩余站数、预计时间/距离）
- 🚏 **站牌页**：参考原版「站点地图」——站点位置地图 + 全部经过线路对比（实时状态/时间/距离），支持「反向站台 / 切换站台」（CMD209）一键换向；选线路复用路线页
- 🗺️ **双地图视图**：路线页可一键切换「站轴 ↔ 地图」，地图视图展示轨迹、编号站点与实时车辆方位
- 🖼️ **常驻地图与全屏地图合一**：开启「地图常驻」后，首页顶部小地图与地图 Tab 共享同一份状态（我的位置、附近站点、相机视角），定位只请求一次，切换无缝衔接、互相同步
- 📍 **附近站点**：geolocator 定位（WGS84→GCJ-02 本地转换）+ CMD106，列出附近站点及各线路实时到站预览，点按直达站牌
- 🕘 **最近与收藏**：查询历史混排去重（上限 20 条）点按直达；线路（带方向）与站点收藏，左滑删除
- 🔄 **页面互通**：路线页双击站点 → 该站站牌页；站牌页点线路 → 路线页（自动定位到本站站序）
- ⚙️ **可调刷新与限速友好**：自动刷新间隔 6–120s 可配，CMD103 线路拓扑按 (城市, 线路, 方向) 内存缓存，规避接口限速风控
- 🌓 **崩溃可追溯**：未捕获异常自动落盘 `crash.log`；桌面端支持鼠标拖拽滚动，各平台使用本地黑体系字体（微软雅黑/苹方/思源黑体）

## 📱 页面导览

| 页面 | 入口 | 说明 |
| --- | --- | --- |
| 首页 | 底部导航 | 顶栏选城市（含定位选城）+ 搜索；中部「附近 / 最近 / 收藏」 |
| 地图 | 底部导航 | 我的位置 + 附近站点 + 城市兜底定位；与首页常驻地图状态互通 |
| 我的 | 底部导航 | 切换城市、刷新间隔、地图常驻开关、站轴方向、关于（版本/构建 commit/仓库地址） |
| 线路详情（路线页） | 搜索线路 / 站牌页选线路 | 时间轴 / 站序条 / 地图三视图，自动定位到所经站看该站预测 |
| 站牌页 | 站点搜索 / 附近列表 / 地图标记 | 站点地图 + 全部经过线路对比（含实时状态）+ 反向站台换向，选线路复用路线页 |

## 🛠️ 技术栈

- **语言**: [Dart](https://dart.dev/)（Flutter SDK ^3.13.2）
- **状态管理**: [provider](https://pub.dev/packages/provider) + `ChangeNotifier`（`AppState` 全局状态 + `MapStore` 共享地图状态）
- **网络**: [dio](https://pub.dev/packages/dio)
- **地图**: [flutter_map](https://pub.dev/packages/flutter_map) + [latlong2](https://pub.dev/packages/latlong2) + 高德栅格瓦片（GCJ-02，零注册 key）
- **定位**: [geolocator](https://pub.dev/packages/geolocator) + 本地 WGS84→GCJ-02 坐标转换；Web 端逆地理编码用 Nominatim（免 key）
- **存储**: [shared_preferences](https://pub.dev/packages/shared_preferences)
- **UI**: Material 3
